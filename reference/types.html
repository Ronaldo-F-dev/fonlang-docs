Entier — kɛn

fon
jo a = 42
jo b = -7
jo c = 1_000_000   // les underscores ne sont pas encore supportés — écrire 1000000

xlɛ(a + b)   // 35
xlɛ(a * b)   // -294

Flottant — kɛn

Un nombre avec point décimal est automatiquement un flottant.

fon
jo pi  = 3.14159
jo tau = 6.28318

xlɛ(pi * 2)       // 6.28318
xlɛ(racine(2.0))  // 1.4142135623730951
Coercition numérique Les opérations mixtes entier/flottant produisent toujours un flottant : 3 + 1.5 → 4.5.

Chaîne — wekwin

Les chaînes sont délimitées par des guillemets doubles. Elles supportent les séquences d'échappement.

fon
jo s = "Mì wá dó !"
jo multi = "ligne1\nligne2\nligne3"
jo tab   = "col1\tcol2"

// Concaténation avec +
xlɛ("Bonjour " + "monde")   // Bonjour monde

// Concaténation avec un nombre
xlɛ("Score : " + 42)        // Score : 42

// Accès à un caractère par index
xlɛ(s[0])   // M

Booléen — nugbo / nuvu

fon
jo vrai = nugbo
jo faux = nuvu

xlɛ(vrai && faux)   // nuvu
xlɛ(vrai || faux)   // nugbo
xlɛ(!vrai)          // nuvu

Null — vɔ / vɔtɔ

vɔ et son alias vɔtɔ représentent l'absence de valeur. Ils sont falsy.

fon
jo rien = vɔ
enyi (rien) {
    xlɛ("jamais atteint")
} alo {
    xlɛ("vɔ est falsy")
}

Tableau — wemawlanxwlɛ

fon
jo arr = [1, "deux", nugbo, [3, 4]]

xlɛ(arr[0])       // 1
xlɛ(arr[1])       // deux
xlɛ(arr[3][1])    // 4  — tableau imbriqué
xlɛ(gaɖiɖi(arr)) // 4

Map — tɛnmɛ

fon
jo m = xa_json("{\"nom\":\"Akɔ\",\"age\":25,\"actif\":true}")

xlɛ(m["nom"])     // Akɔ
xlɛ(m["age"])     // 25
xlɛ(m["actif"])   // nugbo
xlɛ(m["absent"])  // vɔ  (clé inexistante → null)
