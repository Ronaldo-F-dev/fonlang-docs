FonLang/Référence/Mots-clés

Mots-clés

Tous les mots-clés réservés de FonLang, avec leur signification en Fon et leur rôle dans le langage.

Convention Les mots-clés FonLang ne contiennent pas d'accent tonique (les tons sont présents dans la langue orale Fon mais omis dans les identifiants du langage pour simplifier la saisie).

Gestion d'erreurs

Le bloc wli ne prend pas de paramètre. À l'intérieur, la variable gbogbe est automatiquement liée au message d'erreur (type wekwin).

Mot-cléSignification (Fon)Rôle
blokpɔn« essayer »Bloc try
wli« attraper »Bloc catch
gbogbe« exception »Variable auto-injectée dans wli — contient le message d'erreur
fon
blokpɔn {
    jo rep = http_get("https://api.exemple.com")
    xlɛ(rep["corps"])
} wli {
    xlɛ("Erreur :", gbogbe)
}

Programmation orientée objet (OOP)

Les classes et instances sont pleinement implémentées en FonLang.

Mot-cléSignification (Fon)RôleExemple
zɛn« groupe / famille » Définir une classe zɛn Animal { ... }
nu« enfant / issu de » Instancier un objet jo chien = nu Animal("Rex", 3)
sun« commencer » Constructeur de classe sun(n, a) { nyɛ.nom = n }
nyɛ« moi / soi-même » Référence à l'instance courante (this/self) nyɛ.age = nyɛ.age + 1
gu« hériter de » Héritage — la classe enfant hérite des champs et méthodes du parent zɛn Chien gu Animal { ... }
mεjitɔ« père / parent » Référence à la classe parente depuis une méthode (super) mεjitɔ.saluer()
ma_ɖyɔ« fixé / de classe » Méthode statique — appelée sur la classe, pas sur une instance ma_ɖyɔ azɔwanu carre(x) { lɛkɔ x*x }
fon
zɛn Animal {
    jo nom = "inconnu"
    azɔwanu saluer() { xlɛ("Je suis", nyɛ.nom) }
}

zɛn Chien gu Animal {
    jo race = "labrador"

    azɔwanu saluer() {
        mεjitɔ.saluer()          // appel méthode parente
        xlɛ("Race :", nyɛ.race)
    }

    ma_ɖyɔ azɔwanu espece() { lɛkɔ "Canis lupus familiaris" }
}

jo rex = nu Chien()
rex.saluer()
xlɛ(Chien.espece())   // méthode statique
fon
zɛn Compteur {
    jo valeur = 0

    sun(debut) {
        nyɛ.valeur = debut
    }

    azɔwanu incrementer() {
        nyɛ.valeur = nyɛ.valeur + 1
    }

    azɔwanu afficher() {
        xlɛ("Compteur :", nyɛ.valeur)
    }
}

jo c = nu Compteur(10)
c.incrementer()
c.incrementer()
c.afficher()   // Compteur : 12

jo nb = [1,2,3,4,5,6]
jo pairs = xwí(nb, azɔwanu(x) { lɛkɔ x % 2 == 0 })      // [2,4,6]
