Moteur 3D — Phase 3.5 God Hand / PS2 Quality

Toutes les APIs avancées introduites en Phase 3.5 : animation squelettique, shadow maps, normal mapping, transparence, LOD, bloom et color grading. Ces builtins s'ajoutent aux fondations 3D des phases 3.0–3.4.

Prérequis Les APIs de base (scène, caméra, rendu, éclairage) sont décrites dans la référence Stdlib. Cette page documente uniquement les extensions Phase 3.5.

Animation squelettique — GPU Skinning

Charge un modèle .glb exporté depuis Blender avec squelette, puis déforme le mesh en temps réel en appliquant des matrices de pose aux os.

BuiltinSignatureDescription
flɛ3d_glb_skinned flɛ3d_glb_skinned(chemin) → tɛnmɛ Charge un fichier .glb avec squelette. Retourne {"meshes": [...], "skel_id": id}.
flɛ3d_skel_ɖɔ flɛ3d_skel_ɖɔ() → kɛn Crée un squelette vide. Retourne l'identifiant.
flɛ3d_skel_os flɛ3d_skel_os(id, nom, parent, ibm) Ajoute un os au squelette id. parent est l'index de l'os parent (−1 pour la racine). ibm est la inverse bind matrix (tableau de 16 flottants).
flɛ3d_skel_pose flɛ3d_skel_pose(id, joint_idx, mat4) Définit la matrice de pose locale de l'os joint_idx.
flɛ3d_skel_update flɛ3d_skel_update(id) Recalcule toutes les poses mondiales. À appeler après chaque modification de pose.
flɛ3d_skel_kpo flɛ3d_skel_kpo(mesh, skel, noeud, cam, r, g, b) Dessine mesh avec skinning CPU depuis le noeud de scène noeud. r, g, b : teinte multiplicative (1.0 = neutre).
flɛ3d_skel_sunsun flɛ3d_skel_sunsun(id) Libère la mémoire du squelette.
fon
// Charger un personnage avec squelette
jo model   = flɛ3d_glb_skinned("behanzin.glb")
jo mesh_id = model["meshes"][0]
jo skel_id = model["skel_id"]

// Faire tourner l'os de la hanche (index 0) selon le temps t
flɛ3d_skel_pose(skel_id, 0, mat4_trs(v3(0,0,0), quat_euler(0, t, 0), v3(1,1,1)))
flɛ3d_skel_update(skel_id)

// Dessiner avec skinning
flɛ3d_skel_kpo(mesh_id, skel_id, "behanzin", cam, 1.0, 0.9, 0.8)

Shadow Maps

Deux modes d'ombre sont disponibles : une shadow map réelle (passe de profondeur) et une ombre projetée au sol style PS2, sans depth buffer, plus rapide et adaptée aux jeux d'action.

BuiltinSignatureDescription
flɛ3d_ombre_ɖɔ flɛ3d_ombre_ɖɔ(résolution) Initialise la shadow map. résolution : taille en pixels (ex. 512, 1024, 2048).
flɛ3d_ombre_lumiere flɛ3d_ombre_lumiere(dx, dy, dz, cx, cy, cz, portée) Configure la lumière directionnelle pour la shadow map. dx/dy/dz : direction, cx/cy/cz : centre, portée : rayon.
flɛ3d_ombre_rendu flɛ3d_ombre_rendu(mesh_id, noeud) Passe de profondeur — rend mesh_id dans la shadow map. À appeler avant le rendu principal.
flɛ3d_ombre_sol flɛ3d_ombre_sol(mesh_id, noeud, dx, dy, dz, y_sol, cam) Projette une ombre plate sur le plan y = y_sol (style PS2). Pas de depth buffer nécessaire.
flɛ3d_ombre_test flɛ3d_ombre_test(x, y, z) → nugbo/nuvu Retourne nugbo si le point (x, y, z) est dans l'ombre.
fon
// Initialiser la shadow map (512×512)
flɛ3d_ombre_ɖɔ(512)
flɛ3d_ombre_lumiere(-0.5, -1.0, -0.3,  0.0, 0.0, 0.0,  8.0)

// Dans la boucle de jeu :

// 1) Passe de profondeur
flɛ3d_ombre_rendu(mesh_id, "noeud_perso")

// 2) Ombre plate au sol (y = 0)
flɛ3d_ombre_sol(mesh_id, "noeud_perso", -0.5, -1.0, -0.3,  0.0,  cam)

// 3) Vérifier l'ombre sur un point
jo dans_ombre = flɛ3d_ombre_test(px, py, pz)
enyi (dans_ombre) {
    xlɛ("Le point est dans l'ombre")
}

Normal Mapping

Ajoute du relief visuel à un mesh sans augmenter le nombre de polygones, en lisant les normales depuis une texture dédiée.

BuiltinSignatureDescription
flɛ3d_mesh_normalmap flɛ3d_mesh_normalmap(mesh_id, tex_id) Attache une normal map au mesh. Les tangentes sont calculées automatiquement si le mesh possède des UVs et des normales.
fon
// Charger la normal map (canal RVB = normales en espace tangent)
jo nm = flɛ3d_tex("mur_normal.png")

// L'attacher au mesh mur
jo mur = flɛ3d_plan(4.0, 4.0)
flɛ3d_mesh_normalmap(mur, nm)

// Le rendu utilisera automatiquement la normal map
flɛ3d_dessin_trs(mur, cam, v3(0, 2, -5), quat_id(), v3(1,1,1))

Alpha Blending — Transparence

Rend un mesh semi-transparent. Les meshes avec alphaMode=BLEND dans un fichier GLB sont automatiquement transparents à l'import.

BuiltinSignatureDescription
flɛ3d_mesh_alpha flɛ3d_mesh_alpha(mesh_id, alpha) Définit l'opacité du mesh. alpha : flottant de 0.0 (invisible) à 1.0 (opaque).
fon

flɛ3d_mesh_couleur(fumee, 200, 200, 200)

// Rendre la fumée à 35% d'opacité
flɛ3d_mesh_alpha(fumee, 0.35)

// Le mesh GLB avec alphaMode=BLEND est transparent automatiquement
jo vitre = flɛ3d_glb_skinned("vitre.glb")
// → déjà semi-transparent à l'import

LOD — Level of Detail

Sélectionne automatiquement un mesh basse résolution lorsque le personnage ou l'objet dépasse un seuil de distance caméra. Maintient le framerate sur les grandes scènes.

BuiltinSignatureDescription
flɛ3d_mesh_lod flɛ3d_mesh_lod(mesh_hd, mesh_ld, distance) Enregistre la paire LOD. Au-delà de distance unités de la caméra, flɛ3d_dessin_trs utilise automatiquement mesh_ld.
Astuce Appelez flɛ3d_mesh_lod une seule fois à l'initialisation. Ensuite utilisez flɛ3d_dessin_trs(mesh_hd, ...) normalement : le moteur choisit le bon niveau selon la distance.
fon
// Deux résolutions du même arbre
jo arbre_hd = flɛ3d_gltf("arbre_hd.gltf")   // ~2000 triangles
jo arbre_ld = flɛ3d_gltf("arbre_ld.gltf")   // ~200  triangles

// Au-delà de 20 unités : bascule sur le LD
flɛ3d_mesh_lod(arbre_hd, arbre_ld, 20.0)

// Dans la boucle — aucun changement de code
flɛ3d_dessin_trs(arbre_hd, cam, pos, rot, scl)

Post-Processing — Bloom & Color Grading

Effets appliqués sur le framebuffer final. Deux presets prêts à l'emploi reproduisent l'esthétique des jeux PS2 et de God Hand.

BuiltinSignatureDescription
flɛ3d_postfx_godhand flɛ3d_postfx_godhand() Preset God Hand — bloom chaud, contraste élevé, légère teinte rouge-orange. Activation en une ligne.
flɛ3d_postfx_ps2 flɛ3d_postfx_ps2() Preset cinématique PS2 — bloom doux, couleurs légèrement désaturées, vignette prononcée.
flɛ3d_postfx_off flɛ3d_postfx_off() Désactive tous les effets post-processing.
flɛ3d_bloom flɛ3d_bloom(actif, seuil, intensite, rayon) Configure le bloom manuellement. seuil : luminosité minimale pour briller (0–1). intensite : force de l'effet. rayon : rayon de diffusion (pixels).
flɛ3d_colorgrade flɛ3d_colorgrade(lum, cont, sat, vignette) Color grading : lum (luminosité), cont (contraste), sat (saturation), vignette (assombrissement des bords, 0–1).
flɛ3d_teinte flɛ3d_teinte(r, g, b) Ajoute une teinte additive sur le rendu final. Valeurs de −1 à +1.
fon
// Preset tout-en-un
flɛ3d_postfx_godhand()

// Ou configuration manuelle équivalente :
flɛ3d_bloom(nugbo, 0.70, 0.45, 10)       // bloom actif, seuil 70%, intensité 45%, rayon 10px
flɛ3d_colorgrade(1.05, 1.15, 1.10, 0.15) // légère luminosité, contraste fort, sat +10%, vignette 15%
flɛ3d_teinte(0.03, 0.0, -0.03)           // teinte rouge-chaud

// Désactiver entre deux scènes
flɛ3d_postfx_off()

Exemple complet — personnage PS2

Toutes les fonctionnalités Phase 3.5 réunies : animation squelettique, ombre au sol, toon shading et bloom.
