Sauvegarde de jeu

FonctionSignatureDescription
sauvegarder_jeu sauvegarder_jeu(fichier, données) → nugbo Sérialise une map en JSON indenté et l'écrit sur disque. Retourne nugbo si succès.
charger_jeu charger_jeu(fichier) → tɛnmɛ | vɔ Charge et désérialise un fichier JSON. Retourne vɔ si le fichier est absent (première partie).
fon
// Sauvegarder
jo etat = {"score": 1500, "niveau": 4, "vies": 3}
sauvegarder_jeu("save.json", etat)

// Charger avec valeur par défaut via ??
jo etat = charger_jeu("save.json") ?? {"score": 0, "niveau": 1, "vies": 3}
xlɛ("Score :", etat["score"])
