Présentation

FonLang est un langage de programmation impératif dont les mots-clés sont tirés de la langue Fon (Fɔngbè), parlée par plusieurs millions de personnes au Bénin, au Togo et dans la diaspora africaine.

L'objectif est de rendre la programmation accessible dans un contexte culturel et linguistique africain, tout en produisant un langage complet et expressif avec un support natif pour le réseau HTTP, les fichiers, le JSON et la manipulation de données.

Fonctionnalités

💬

Syntaxe Fon

Mots-clés tirés de la langue Fon. Conditions entre parenthèses, blocs avec {}.

⚡

Fonctions de première classe

Closures, fonctions anonymes, variadiques, récursion et fonctions d'ordre supérieur.

📦

Collections natives

Tableaux wemawlanxwlɛ, maps associatives, for-in avec ɖo.

🌐

HTTP & JSON

Requêtes GET/POST, encodage/décodage JSON, tout nativement disponible.

📁

Fichiers

Lecture, écriture, vérification et suppression de fichiers avec wema_*.

🔢

Mathématiques

Trigonométrie, racine carrée, puissance, arrondi, valeur absolue et plus encore.

Aperçu rapide

fon 
// Déclaration de variables
jo nom = "Akɔ"
jo age  = 25

// Condition
enyi (age >= 18) {
    xlɛ(nom + " est majeur·e")
} alo {
    xlɛ(nom + " est mineur·e")
}

// Boucle for classique
jo somme = 0
sin (jo i = 1; i <= 10; i++) {
    somme = somme + i
}
xlɛf("Somme 1..10 = %d\n", somme)

// For-in sur un tableau
jo fruits = ["mangue", "papaye", "ananas"]
sin (fruit ɖo fruits) {
    xlɛ(fruit)
}

// Fonction récursive
azɔwanu factorielle(n) {
    enyi (n == 0) { lɛkɔ 1 }
    alo { lɛkɔ n * factorielle(n - 1) }
}
xlɛ("6! = " + factorielle(6))

Démarrage en 30 secondes

bash 
# Cloner et compiler
git clone https://github.com/fonlang/fonlang
cd fonlang
go build -o fonlang ./cmd/fonlang

# Exécuter un fichier .fon
./fonlang monprogramme.fon

# Lancer le REPL interactif
./fonlang
