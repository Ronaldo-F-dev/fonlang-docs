Programmation orientée objet

Classes, instances, héritage et méthodes statiques en FonLang.

Définir une classe — zɛn

zɛn signifie « type » ou « catégorie » en Fon. Une classe regroupe des champs et des méthodes.

fon
zɛn Animal {
    jo nom = "inconnu"

    sun(n) {
        nyɛ.nom = n
    }

    azɔwanu cri() {
        xlɛ(nyɛ.nom + " fait un son")
    }
}
Étymologie : zɛn = catégorie / type · sun = constructeur (« mettre en place ») · nyɛ = « moi » (référence à l'instance courante)

Instancier — nu

nu signifie « chose » ou « objet » en Fon. Il crée une nouvelle instance de la classe.

fon
jo chat = nu Animal("Minou")
chat.cri()   // Minou fait un son

xlɛ(chat.nom)   // Minou

Constructeur — sun

Le constructeur sun est appelé automatiquement à la création de l'instance. Il reçoit les arguments passés à nu Classe(...).

fon
zɛn Point {
    jo x = 0
    jo y = 0

    sun(px, py) {
        nyɛ.x = px
        nyɛ.y = py
    }

    azɔwanu afficher() {
        xlɛf("(%d, %d)\n", nyɛ.x, nyɛ.y)
    }
}

jo p = nu Point(3, 7)
p.afficher()   // (3, 7)

Héritage — gu

gu signifie « avec » ou « qui vient de » en Fon. Une classe enfant hérite de tous les champs et méthodes de son parent.

fon
zɛn Animal {
    jo nom = ""
    sun(n) { nyɛ.nom = n }

    azɔwanu cri() { xlɛ("...") }
    azɔwanu presenter() { xlɛ("Je suis " + nyɛ.nom) }
}

zɛn Chien gu Animal {
    azɔwanu cri() { xlɛ("Waf !") }
}

zɛn Chat gu Animal {
    azɔwanu cri() { xlɛ("Miaou !") }
}

jo d = nu Chien("Rex")
d.presenter()   // Je suis Rex
d.cri()         // Waf !

jo c = nu Chat("Minou")
c.presenter()   // Je suis Minou  (méthode héritée)
c.cri()         // Miaou !

Super — mεjitɔ

mεjitɔ signifie « ancêtre » ou « parent » en Fon. Il permet d'appeler une méthode de la classe parente depuis la classe enfant.

fon
zɛn Forme {
    azɔwanu description() { lɛkɔ "forme" }
}

zɛn Cercle gu Forme {
    jo rayon = 0
    sun(r) { nyɛ.rayon = r }

    azɔwanu description() {
        jo base = mεjitɔ.description()
        lɛkɔ base + " ronde (r=" + wekwin(nyɛ.rayon) + ")"
    }
}

jo c = nu Cercle(5)
xlɛ(c.description())   // forme ronde (r=5)
Note : mεjitɔ peut aussi être utilisé dans le constructeur pour appeler le constructeur parent : mεjitɔ.sun(args).

Méthodes statiques — ma_ɖyɔ

ma_ɖyɔ signifie « de la maison » (appartenant à la classe, pas à l'instance). Les méthodes statiques s'appellent directement sur la classe, sans instance.

fon
zɛn Maths {
    ma_ɖyɔ azɔwanu carre(x) { lɛkɔ x * x }
    ma_ɖyɔ azɔwanu cube(x)  { lɛkɔ x * x * x }
}

xlɛ(Maths.carre(4))   // 16
xlɛ(Maths.cube(3))    // 27

Exemple complet — jeu de rôle

fon
zɛn Personnage {
    jo nom  = ""
    jo vie  = 100
    jo force = 10

    sun(n, v, f) {
        nyɛ.nom   = n
        nyɛ.vie   = v
        nyɛ.force = f
    }

    azɔwanu attaquer(cible) {
        cible.vie = cible.vie - nyɛ.force
        xlɛ(nyɛ.nom + " attaque " + cible.nom)
    }

    azɔwanu estVivant() { lɛkɔ nyɛ.vie > 0 }

    azɔwanu statut() {
        xlɛf("%s — vie: %d\n", nyɛ.nom, nyɛ.vie)
    }
}

zɛn Guerrier gu Personnage {
    jo bouclier = 5

    sun(n) { mεjitɔ.sun(n, 150, 20) }

    azɔwanu defendre() {
        nyɛ.vie = nyɛ.vie + nyɛ.bouclier
        xlɛ(nyɛ.nom + " se défend !")
    }
}

jo hero  = nu Guerrier("Tobi")
jo ennemi = nu Personnage("Zombie", 50, 5)

hero.statut()            // Tobi — vie: 150
hero.attaquer(ennemi)    // Tobi attaque Zombie
ennemi.statut()          // Zombie — vie: 30
hero.defendre()          // Tobi se défend !
hero.statut()            // Tobi — vie: 155
