Bibliothèques standard

HTTP, fichiers, JSON, date/heure, mathématiques et plus.

Date & Heure

fon
xlɛ(egbe())          // "2026-04-28"       — date du jour
xlɛ(azan())          // "2026-04-28 14:30:00" — date et heure
xlɛ(gan())           // 14                 — heure courante (0–23)
xlɛ(nukunxwixwe())   // 42                 — secondes courantes (0–59)

HTTP

Les fonctions HTTP retournent une map avec les clés "corps" et "statut". Le timeout est configurable (défaut : 10 s).

fon
// Requête GET
jo rep = http_get("https://api.github.com")
xlɛ(rep["statut"])   // 200
xlɛ(rep["corps"])    // corps JSON de la réponse

// Requête GET avec timeout personnalisé (secondes)
jo rep_rapide = http_get("https://api.github.com", 5)

// Requête POST
jo corps = json_ecrire(json_xa("{\"titre\":\"test\"}"))
jo rep2 = http_post("https://httpbin.org/post", corps)
xlɛ(rep2["statut"])

Interpolation de chaînes

Insérez n'importe quelle expression FonLang directement dans une chaîne avec la syntaxe ${...}. L'expression est évaluée et convertie en texte automatiquement.

fon
jo nom = "Ronaldo"
jo score = 1450

// Concaténation classique
xlɛ("Bonjour " + nom + " ! Score : " + wekwin(score))

// Avec interpolation — plus lisible
xlɛ("Bonjour ${nom} ! Score : ${score}")

// Expressions complètes entre ${ }
jo vies = 3
xlɛ("Vies restantes : ${vies * 2 - 1}")   // "Vies restantes : 5"

// Appel de méthode
jo joueur = { "nom": "Koku", "pts": 88 }
xlɛ("Joueur ${joueur["nom"]} — ${joueur["pts"]} pts")

Conversions de type

fon
// Vers nombre
xlɛ(kɛn("42"))      // 42
xlɛ(toInt("3.14"))  // 3  (troncature)

// Vers chaîne
xlɛ(wekwin(42))     // "42"
xlɛ(toString(nugbo)) // "nugbo"

// Vers booléen
xlɛ(toBool(0))      // nuvu (faux)
xlɛ(toBool(1))      // nugbo (vrai)
xlɛ(toBool(""))     // nuvu (faux)
xlɛ(toBool(vɔ))     // nuvu (faux)

Gestion d'erreurs

Utilisez blokpɔn / wli pour capturer les erreurs à l'exécution. La variable gbogbe est automatiquement disponible dans le bloc wli.

fon
blokpɔn {
    jo contenu = wema_xa("/tmp/config.txt")
    xlɛ(contenu)
} wli {
    xlɛ("Erreur :", gbogbe)
}

Modules

kplawa charge un fichier .fon et l'exécute dans la portée courante. Toutes ses fonctions et variables deviennent accessibles.

fon
// utils.fon
azɔwanu double(x) { lɛkɔ x * 2 }

// main.fon
kplawa "utils.fon"
xlɛ(double(21))   // 42

Tableaux — ordre supérieur

xwí (« filtrer ») et ɖekpo (« réduire ») sont des builtins qui acceptent une fonction en argument.

FonctionRetourRôle
xwí(tableau, fn) tableau Retourne un nouveau tableau ne contenant que les éléments pour lesquels fn retourne nugbo.
ɖekpo(tableau, fn, init) valeur Réduit le tableau à une seule valeur en appelant fn(accumulateur, element) pour chaque élément, en partant de init.
fon
jo nums = [1, 2, 3, 4, 5, 6]

// Garder les pairs
jo pairs = xwí(nums, azɔwanu(x) { lɛkɔ x % 2 == 0 })
xlɛ(pairs)   // [2, 4, 6]

// Calculer la somme
jo somme = ɖekpo(nums, azɔwanu(acc, x) { lɛkɔ acc + x }, 0)
xlɛ(somme)   // 21

// Combinaison : somme des pairs
jo resultat = ɖekpo(
    xwí(nums, azɔwanu(x) { lɛkɔ x % 2 == 0 }),
    azɔwanu(acc, x) { lɛkɔ acc + x },
    0
)
xlɛ(resultat)   // 12

Collision 2D

Fonctions de détection de collision pour le moteur de jeu.

FonctionRetourRôle
aabb(x1, y1, w1, h1, x2, y2, w2, h2) booléen Collision AABB (Axis-Aligned Bounding Box) entre deux rectangles.
cercle_collide(x1, y1, r1, x2, y2, r2) booléen Collision entre deux cercles définis par leur centre et rayon.
fon
// Collision AABB
jo touche = aabb(10, 10, 50, 50,  40, 40, 50, 50)
xlɛ("Rectangles se touchent : " + touche)   // nugbo

// Collision cercles
jo c = cercle_collide(0, 0, 30,  50, 0, 30)
xlɛ("Cercles se touchent : " + c)           // gbɔ
