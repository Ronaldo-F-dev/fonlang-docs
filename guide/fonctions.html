FonLang/Guide/Fonctions

Fonctions

Fonctions nommées, anonymes, variadiques et closures.

Déclaration — azɔwanu

Le mot azɔwanu signifie « travailleur » / « celui qui fait » en Fon.

fon
azɔwanu additionner(a, b) {
    lɛkɔ a + b
}

xlɛ(additionner(3, 4))   // 7

Retour de valeur — lɛkɔ

lɛkɔ signifie « retourner » en Fon. La valeur de la dernière expression d'un bloc est implicitement retournée si lɛkɔ est absent.

fon
azɔwanu max(a, b) {
    enyi (a > b) { lɛkɔ a }
    alo          { lɛkɔ b }
}

xlɛ(max(10, 7))   // 10

Récursion

fon
azɔwanu factorielle(n) {
    enyi (n == 0) { lɛkɔ 1 }
    alo { lɛkɔ n * factorielle(n - 1) }
}

xlɛ(factorielle(6))   // 720

azɔwanu fib(n) {
    enyi (n <= 1) { lɛkɔ n }
    alo { lɛkɔ fib(n - 1) + fib(n - 2) }
}

xlɛ(fib(10))   // 55

Fonctions anonymes (lambda)

Une fonction sans nom peut être stockée dans une variable ou passée en argument.

fon
jo double = azɔwanu(x) { lɛkɔ x * 2 }
xlɛ(double(21))   // 42

jo carre = azɔwanu(x) { lɛkɔ x * x }
xlɛ(carre(9))     // 81

Closures

Les fonctions capturent leur environnement lexical.

fon
azɔwanu creerCompteur() {
    jo compte = 0
    lɛkɔ azɔwanu() {
        compte++
        lɛkɔ compte
    }
}

jo c = creerCompteur()
xlɛ(c())   // 1
xlɛ(c())   // 2
xlɛ(c())   // 3

Fonctions variadiques

Le paramètre ...rest collecte tous les arguments supplémentaires dans un tableau.

fon
azɔwanu somme(...nombres) {
    jo total = 0
    sin (n ɖo nombres) {
        total = total + n
    }
    lɛkɔ total
}

xlɛ(somme(1, 2, 3, 4, 5))   // 15
xlɛ(somme(10, 20))           // 30

Fonctions d'ordre supérieur

Les fonctions peuvent être passées en argument et retournées.

fon
// Applique fn sur chaque élément du tableau
azɔwanu appliquer(arr, fn) {
    jo resultat = []
    sin (x ɖo arr) {
        resultat = gɔna(resultat, fn(x))
    }
    lɛkɔ resultat
}

jo nums = [1, 2, 3, 4, 5]
jo doubles = appliquer(nums, azɔwanu(x) { lɛkɔ x * 2 })
xlɛ(doubles)   // [2, 4, 6, 8, 10]

Génériques — azɔwanu<T>

FonLang supporte les fonctions génériques par type erasure. Le paramètre de type est ignoré à l'exécution (le langage est dynamique) mais documente l'intention et permet une vérification statique de base par l'analyseur sémantique.

fon
// Identité générique
azɔwanu identite<T>(x: T): T {
    lɛkɔ x
}

// Premier élément d'un tableau
azɔwanu premier<T>(arr: wemawlanxwlɛ): T {
    lɛkɔ arr[0]
}

// Paire générique avec deux types
azɔwanu paire<A, B>(a: A, b: B) {
    lɛkɔ [a, b]
}

xlɛ(identite(42))             // 42
xlɛ(identite("Bonjour Fon")) // "Bonjour Fon"
xlɛ(premier([10, 20, 30]))    // 10
xlɛ(paire("score", 500))      // ["score", 500]

Async / Await — ayihun / yɔ

ayihun lance une expression dans une goroutine et retourne un Future. yɔ bloque jusqu'à ce que le Future soit résolu.

fon
azɔwanu fetch(url) {
    lɛkɔ http_get(url)   // requête réseau
}

// Lancer deux requêtes en parallèle
jo f1 = ayihun fetch("api.fon/joueurs")
jo f2 = ayihun fetch("api.fon/scores")

xlɛ("En attente...")

// Attendre les résultats (bloquant)
jo joueurs = yɔ f1
jo scores  = yɔ f2

xlɛ(joueurs)
xlɛ(scores)
Compatibilité avec ??
Combinez ayihun et ?? pour des valeurs par défaut :
jo config = (yɔ charger_async("cfg.json")) ?? {"fps": 60}
