fon run — Interpréteur

Exécute directement un fichier .fon via l'interpréteur tree-walking. Aucun binaire n'est produit.

bash
fon run hello.fon
fon run examples/poo.fon
Quand utiliser fon run ? Développement quotidien, scripts, prototypage rapide. Pas besoin de clang.

fon build — Compilation native

Compile un fichier .fon vers un binaire natif via LLVM IR + clang. Le binaire produit tourne sans Go installé.

bash
# Compilation simple (binaire dans le même dossier que la source)
fon build hello.fon

# Spécifier le nom du binaire de sortie
fon build hello.fon -o /usr/local/bin/hello

# Compiler puis exécuter
fon build hello.fon -o hello && ./hello

Prérequis pour fon build

  • clang — compilateur C/LLVM
bash
# Linux (Debian/Ubuntu)
sudo apt install clang

# macOS
xcode-select --install

# Windows — MinGW-w64
# https://www.mingw-w64.org/

fon fmt — Formateur automatique

Reformate un ou plusieurs fichiers .fon en place selon le style canonique FonLang :

  • Indentation par tabulations (un niveau par paire de { }).
  • Suppression des espaces en fin de ligne.
  • Conservation d'une seule ligne vide consécutive maximum.
  • Espaces normalisés autour des opérateurs binaires (+, -, ==, =, etc.).
  • Espace après chaque virgule dans les listes d'arguments.
  • Pas d'espace à l'intérieur des parenthèses d'appel de fonction.
  • Les accolades à l'intérieur des chaînes et des commentaires ne sont pas comptées.
bash
# Formater un fichier
fon fmt mon_programme.fon

# Formater plusieurs fichiers d'un coup
fon fmt src/*.fon

# Vérifier si un fichier serait modifié (dry-run avec diff)
fon fmt mon_programme.fon && echo "Déjà formaté"
Workflow recommandé — Lancez fon fmt avant chaque commit, exactement comme gofmt ou black. Les fichiers déjà au bon format ne sont pas touchés ; fon fmt affiche uniquement les chemins des fichiers modifiés.

fon test — Framework de tests unitaires

Exécute les fichiers *_test.fon et rapporte chaque assertion en couleur. Sans arguments, fon test découvre automatiquement tous les fichiers *_test.fon dans le répertoire courant.

BuiltinArgumentsRôle
tɛn(cond, msg)nugbo/nuvu, wekwinÉchoue si cond est faux.
tɛn_egal(a, b, msg)tout×2, wekwinÉchoue si a ≠ b.
tɛn_diff(a, b, msg)tout×2, wekwinÉchoue si a = b.
tɛn_vrai(v, msg)tout, wekwinÉchoue si v est falsy.
tɛn_faux(v, msg)tout, wekwinÉchoue si v est truthy.
tɛn_groupe(nom, fn)wekwin, azɔwanuRegroupe des assertions sous un label.
fon
// math_test.fon

tɛn_groupe("Addition", azɔwanu() {
    tɛn(2 + 3 == 5, "2 + 3 = 5")
    tɛn_egal(10 + 5, 15, "10 + 5 = 15")
})

tɛn_groupe("Tableaux", azɔwanu() {
    jo a = [1, 2]
    jo b = [3, 4]
    jo c = [...a, ...b]
    tɛn_egal(gaɖiɖi(c), 4, "spread: longueur 4")
    tɛn_egal(c[0], 1, "premier élément")
})
bash
# Lancer tous les *_test.fon du répertoire courant
fon test

# Lancer des fichiers spécifiques
fon test math_test.fon chaines_test.fon

fon install — Gestionnaire de paquets

Installe un paquet FonLang depuis n'importe quel dépôt Git public. Les paquets sont stockés dans ~/.fon/packages/. Après l'installation, fon install affiche le chemin kplawa à utiliser dans votre code.

bash
# Installer un paquet depuis GitHub
fon install github.com/utilisateur/mon-paquet

# Installer une version précise (tag ou branche)
fon install github.com/utilisateur/mon-paquet@v1.2.0

# Lister les paquets installés
fon list

# Supprimer un paquet
fon remove github.com/utilisateur/mon-paquet

# Mettre à jour tous les paquets installés
fon upgrade

# Afficher les détails d'un paquet (commit, fichiers .fon)
fon info github.com/utilisateur/mon-paquet
fon
// Dans votre programme, après fon install :
kplawa "/home/utilisateur/.fon/packages/github.com/utilisateur/mon-paquet/main.fon"
Prérequis — git doit être disponible dans le PATH. Les paquets sont de simples dépôts Git contenant des fichiers .fon.

fon help et fon version

bash
# Afficher l'aide générale
fon help

# Aide sur une commande spécifique
fon help build

# Version de FonLang
fon version

Installation globale

Pour utiliser fon depuis n'importe quel répertoire :

bash
# Compiler la CLI
git clone https://github.com/OtinielGodwin/fon-programming.git
cd fon-programming
go build -o fon ./cmd/fon

# Installer globalement
sudo cp fon /usr/local/bin/fon

# Vérifier
fon version
