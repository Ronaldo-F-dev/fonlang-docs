CLI fon

Interprétez ou compilez vos programmes FonLang depuis le terminal.

Vue d'ensemble

La CLI fon offre deux modes d'exécution :

CommandeModeVitessePrérequis
fon runInterpréteurImmédiatGo uniquement
fon buildCompilation native (LLVM)Plus rapide à l'exécutionGo + clang

fon run — Interpréteur

Exécute directement un fichier .fon via l'interpréteur tree-walking. Aucun binaire n'est produit.

bash
fon run hello.fon
fon run examples/poo.fon
Quand utiliser fon run ? Développement quotidien, scripts, prototypage rapide. Pas besoin de clang.

fon build — Compilation native

Compile un fichier .fon vers un binaire natif via LLVM IR + clang. Le binaire produit tourne sans Go installé.

bash
# Compilation simple (binaire dans le même dossier que la source)
fon build hello.fon

# Spécifier le nom du binaire de sortie
fon build hello.fon -o /usr/local/bin/hello

# Compiler puis exécuter
fon build hello.fon -o hello && ./hello

Prérequis pour fon build

  • clang — compilateur C/LLVM
bash
# Linux (Debian/Ubuntu)
sudo apt install clang

# macOS
xcode-select --install

# Windows — MinGW-w64
# https://www.mingw-w64.org/

fon help et fon version

bash
# Afficher l'aide générale
fon help

# Aide sur une commande spécifique
fon help build

# Version de FonLang
fon version

Installation globale

Pour utiliser fon depuis n'importe quel répertoire :

bash
# Compiler la CLI
git clone https://github.com/OtinielGodwin/fon-programming.git
cd fon-programming
go build -o fon ./cmd/fon

# Installer globalement
sudo cp fon /usr/local/bin/fon

# Vérifier
fon version
