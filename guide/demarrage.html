Démarrage rapide

Installez FonLang et écrivez votre premier programme en quelques minutes.

Installation

Prérequis

  • Go 1.21 ou supérieur
  • Git

Compiler depuis les sources

bash
git clone https://github.com/fonlang/fonlang
cd fonlang
make all        # compile fonlang + fonlang-lsp + fonlang-dap
# ou manuellement :
go build -o fonlang     ./cmd/fonlang
go build -o fonlang-lsp ./cmd/fonlang-lsp
go build -o fonlang-dap ./cmd/fonlang-dap

Extension VS Code

L'extension FonLang pour VS Code (v0.4.0) intègre :

  • Syntax highlighting — mots-clés, strings, opérateurs
  • LSP — autocomplétion, hover, go-to-definition, diagnostics en temps réel (via fonlang-lsp)
  • DAP — debugger pas-à-pas : breakpoints, step-over, inspection de variables (via fonlang-dap)
  • Commandes — exécuter, compiler, WASM, formater, tester depuis l'éditeur
  • Snippets — async, génériques, pattern matching, savestate, etc.

Installez fonlang-lsp et fonlang-dap dans votre PATH, puis installez l'extension .vsix.

Premier programme

Créez un fichier bonjour.fon :

fon
xlɛ("Mì wá dó, monde !")

jo nom = "Akɔ"
jo age  = 25

enyi (age >= 18) {
    xlɛ(nom + " est majeur·e")
} alo {
    xlɛ(nom + " est mineur·e")
}
bash
./fonlang bonjour.fon
# Mì wá dó, monde !
# Akɔ est majeur·e

Le REPL interactif

Sans argument, fonlang démarre un REPL évaluant le code en temps réel :

bash
./fonlang
# FonLang 0.1.0-alpha — REPL interactif

fon> jo x = 10
=> 10
fon> x * x
=> 100
fon> xlɛ("résultat : " + x)
résultat : 10
Astuce Les blocs multi-lignes sont reconnus automatiquement : saisissez une ligne avec {, puis continuez sur les lignes suivantes — le REPL attend la fermeture } avant d'évaluer.

Structure d'un programme

Un programme FonLang est une séquence d'instructions. Les points-virgules sont facultatifs entre lignes séparées, obligatoires pour plusieurs instructions sur une même ligne.

fon
// Commentaire sur une ligne

jo a = 1           // déclaration
jo b = 2
xlɛ(a + b)         // affiche 3

jo x = 10; jo y = 20; xlɛ(x + y)   // plusieurs sur une ligne
