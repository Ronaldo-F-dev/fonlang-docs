FonLang/Guide/Interface graphique

Interface graphique (flɛsɛ)

Créez des fenêtres, dessinez des formes et gérez les entrées clavier/souris directement depuis FonLang grâce au moteur Ebiten.

flɛsɛ signifie « fenêtre » en Fon. Le mot-clé hun_flɛtɛli veut dire « ouvrir la fenêtre » et flɛtɛli_boucle veut dire « boucle de la fenêtre ».

Hello World graphique

fon
hun_flɛtɛli("Mì wá dó", 800, 600)   // ouvrir la fenêtre 800×600

azɔwanu mise_a_jour() {
    enyi (flɛ_touche("echap")) { su_flɛtɛli() }
}

azɔwanu dessin() {
    flɛ_couleur(30, 30, 30)                          // fond sombre
    flɛ_signon("Mì wá dó !", 300, 280, 255, 255, 255) // texte blanc
}

flɛtɛli_boucle(mise_a_jour, dessin)  // démarrer (bloquant)

Gestion de la fenêtre

FonctionArgumentsRôle
hun_flɛtɛli(titre, w, h) wekwin, kɛn, kɛn Initialise la fenêtre (titre, largeur, hauteur). À appeler avant tout.
su_flɛtɛli() — Ferme la fenêtre et arrête la boucle.
flɛtɛli_boucle(fn_update, fn_draw) azɔwanu, azɔwanu Démarre le game loop. Bloquant — appel terminal du programme.

Fonctions de dessin

Les fonctions de dessin ne s'exécutent correctement qu'à l'intérieur du callback fn_draw.

FonctionArgumentsRôle
flɛ_couleur(r, g, b) kɛn×3 Efface l'écran avec une couleur unie (RVB 0–255). Appelée en premier dans draw.
flɛ_xwe(x, y, w, h, r, g, b) kɛn×7 Dessine un rectangle plein à (x, y), taille w×h, couleur RVB.
flɛ_kpo(x, y, rayon, r, g, b) kɛn×6 Dessine un cercle plein centré en (x, y) de rayon donné.
flɛ_ligne(x1, y1, x2, y2, r, g, b) kɛn×7 Dessine une ligne entre (x1, y1) et (x2, y2).
flɛ_signon(texte, x, y, r, g, b) wekwin, kɛn×5 Affiche du texte à la position (x, y) avec la couleur RVB.
fon
azɔwanu dessin() {
    flɛ_couleur(0, 0, 0)                        // fond noir
    flɛ_xwe(50, 50, 200, 100, 255, 0, 0)        // rectangle rouge
    flɛ_kpo(400, 300, 60, 0, 200, 255)          // cercle cyan
    flɛ_ligne(0, 0, 800, 600, 255, 255, 0)      // diagonale jaune
    flɛ_signon("Score : 42", 20, 20, 255, 255, 255)
}

Clavier et souris

FonctionRetourRôle
flɛ_touche(nom) nugbo/nuvu Retourne vrai si la touche nommée est enfoncée à cette frame.
flɛ_souris() map {x, y} Position courante du curseur en pixels.
flɛ_souris_clic() nugbo/nuvu Vrai si le bouton gauche de la souris est enfoncé.
flɛ_touche_appuyee(nom) nugbo/nuvu Vrai uniquement au frame où la touche vient d'être pressée (edge-trigger).
flɛ_touche_relachee(nom) nugbo/nuvu Vrai uniquement au frame où la touche vient d'être relâchée.
flɛ_clic_appuye() nugbo/nuvu Vrai uniquement au frame où le bouton gauche vient d'être cliqué.

Noms de touches reconnus

Nom FonLangTouche

fon
azɔwanu mise_a_jour() {
    enyi (flɛ_touche("gauche"))  { jo x = x - 4 }
    enyi (flɛ_touche("droite"))  { jo x = x + 4 }
    enyi (flɛ_touche("haut"))    { jo y = y - 4 }
    enyi (flɛ_touche("bas"))     { jo y = y + 4 }
    enyi (flɛ_touche("echap"))   { su_flɛtɛli() }

    jo souris = flɛ_souris()
    enyi (flɛ_souris_clic()) {
        xlɛ("Clic en", souris["x"], souris["y"])
    }
}

Images et audio

FonctionRetourRôle
flɛ_ɖiɖe(chemin, x, y) vɔ Charge et affiche une image PNG ou JPEG à la position (x, y). Cache automatique — pas de rechargement à chaque frame.
flɛ_ɖiɖe_echelle(chemin, x, y, sx, sy) vɔ Affiche une image avec mise à l'échelle. sx=2 double la largeur, sy=0.5 divise la hauteur par deux.
flɛ_ɖiɖe_rotation(chemin, x, y, angle) vɔ Affiche une image tournée de angle degrés (sens horaire) autour de son centre.
flɛ_ɖiɖe_ex(chemin, x, y, sx, sy, angle) vɔ Combinaison complète : mise à l'échelle et rotation en un seul appel.
flɛ_asanhún(chemin) vɔ Joue un fichier audio WAV (non bloquant). Utilise aplay/paplay sous Linux, afplay sous macOS.

Détection de collision

Ces fonctions sont disponibles en dehors du contexte GUI — elles s'utilisent dans la logique de mise à jour (mise_a_jour).

FonctionRetourRôle
aabb(x1,y1,w1,h1, x2,y2,w2,h2) nugbo/nuvu Retourne vrai si les deux rectangles axés se chevauchent (Axis-Aligned Bounding Box).
cercle_collide(x1,y1,r1, x2,y2,r2) nugbo/nuvu Retourne vrai si la distance entre les deux centres est inférieure à la somme des rayons.
fon
// Balle (cercle) contre un mur (rectangle)
enyi (aabb(bx-r, by-r, r*2, r*2, mx, my, mw, mh)) {
    jo dx = dx * -1   // rebond
}

// Deux balles
enyi (cercle_collide(b1x, b1y, r1, b2x, b2y, r2)) {
    xlɛ("collision !")
}

Fenêtre et timing

FonctionRetourRôle
flɛ_largeur() kɛn (entier) Largeur de la fenêtre en pixels.
flɛ_jiyiyi() kɛn (entier) Hauteur de la fenêtre en pixels.
flɛ_dt() kɛn (flottant) Delta time — secondes depuis le dernier frame. Idéal pour des mouvements indépendants du framerate.
flɛ_fps() kɛn (flottant) Nombre d'images par seconde actuelles.
fon
azɔwanu mise_a_jour() {
    jo dt = flɛ_dt()
    jo bx = bx + vitesse * dt   // mouvement indépendant du FPS
}

azɔwanu dessin() {
    flɛ_couleur(0, 0, 0)
    flɛ_ɖiɖe("fond.png", 0, 0)
    flɛ_signon("FPS: " + toInt(flɛ_fps()), 10, 10, 255, 255, 0)
}

Exemple complet — balle rebondissante

fon
hun_flɛtɛli("Balle", 800, 600)

jo bx = 400   jo by = 300
jo dx = 3     jo dy = 2
jo r  = 20

azɔwanu mise_a_jour() {
    jo bx = bx + dx
    jo by = by + dy

    enyi (bx - r < 0 abi bx + r > 800) { jo dx = dx * -1 }
    enyi (by - r < 0 abi by + r > 600) { jo dy = dy * -1 }

    enyi (flɛ_touche("echap")) { su_flɛtɛli() }
}

azɔwanu dessin() {
    flɛ_couleur(20, 20, 40)
    flɛ_kpo(bx, by, r, 255, 80, 80)
    flɛ_signon("Appuyez Échap pour quitter", 10, 10, 180, 180, 180)
}

flɛtɛli_boucle(mise_a_jour, dessin)
Note technique — Sur Linux, FonLang utilise Ebiten avec le backend X11 (GLFW). Assurez-vous que les bibliothèques système libX11, libGL et libXxf86vm sont disponibles.
