FonLang/Guide/Interface graphique

Interface graphique (flɛsɛ)

Créez des fenêtres, dessinez des formes et gérez les entrées clavier/souris directement depuis FonLang grâce au moteur Ebiten.

flɛsɛ signifie « fenêtre » en Fon. Le mot-clé hun_flɛtɛli veut dire « ouvrir la fenêtre » et flɛtɛli_boucle veut dire « boucle de la fenêtre ».

Hello World graphique

fon
hun_flɛtɛli("Mì wá dó", 800, 600)   // ouvrir la fenêtre 800×600

azɔwanu mise_a_jour() {
    enyi (flɛ_touche("echap")) { su_flɛtɛli() }
}

azɔwanu dessin() {
    flɛ_couleur(30, 30, 30)                          // fond sombre
    flɛ_signon("Mì wá dó !", 300, 280, 255, 255, 255) // texte blanc
}

flɛtɛli_boucle(mise_a_jour, dessin)  // démarrer (bloquant)

Gestion de la fenêtre

FonctionArgumentsRôle
hun_flɛtɛli(titre, w, h) wekwin, kɛn, kɛn Initialise la fenêtre (titre, largeur, hauteur). À appeler avant tout.
su_flɛtɛli() — Ferme la fenêtre et arrête la boucle.
flɛtɛli_boucle(fn_update, fn_draw) azɔwanu, azɔwanu Démarre le game loop. Bloquant — appel terminal du programme.

Fonctions de dessin

Les fonctions de dessin ne s'exécutent correctement qu'à l'intérieur du callback fn_draw.

FonctionArgumentsRôle
flɛ_couleur(r, g, b) kɛn×3 Efface l'écran avec une couleur unie (RVB 0–255). Appelée en premier dans draw.
flɛ_xwe(x, y, w, h, r, g, b) kɛn×7 Dessine un rectangle plein à (x, y), taille w×h, couleur RVB.
flɛ_kpo(x, y, rayon, r, g, b) kɛn×6 Dessine un cercle plein centré en (x, y) de rayon donné.
flɛ_ligne(x1, y1, x2, y2, r, g, b) kɛn×7 Dessine une ligne entre (x1, y1) et (x2, y2).
flɛ_signon(texte, x, y, r, g, b) wekwin, kɛn×5 Affiche du texte à la position (x, y) avec la couleur RVB.
fon
azɔwanu dessin() {
    flɛ_couleur(0, 0, 0)                        // fond noir
    flɛ_xwe(50, 50, 200, 100, 255, 0, 0)        // rectangle rouge
    flɛ_kpo(400, 300, 60, 0, 200, 255)          // cercle cyan
    flɛ_ligne(0, 0, 800, 600, 255, 255, 0)      // diagonale jaune
    flɛ_signon("Score : 42", 20, 20, 255, 255, 255)
}

Clavier et souris

FonctionRetourRôle
flɛ_touche(nom) nugbo/nuvu Retourne vrai si la touche nommée est enfoncée à cette frame.
flɛ_souris() map {x, y} Position courante du curseur en pixels.
flɛ_souris_clic() nugbo/nuvu Vrai si le bouton gauche de la souris est enfoncé.
flɛ_touche_appuyee(nom) nugbo/nuvu Vrai uniquement au frame où la touche vient d'être pressée (edge-trigger).
flɛ_touche_relachee(nom) nugbo/nuvu Vrai uniquement au frame où la touche vient d'être relâchée.
flɛ_clic_appuye() nugbo/nuvu Vrai uniquement au frame où le bouton gauche vient d'être cliqué.

Noms de touches reconnus

Nom FonLangTouche
"espace"Barre espace
"entree"Entrée
"echap"Échap
"maj"Majuscule (Shift)
"ctrl" / "alt"Ctrl / Alt
"gauche" / "droite" / "haut" / "bas"Flèches directionnelles
"f1" – "f12"Touches de fonction
"a" – "z"Lettres
"0" – "9"Chiffres
fon
azɔwanu mise_a_jour() {
    enyi (flɛ_touche("gauche"))  { jo x = x - 4 }
    enyi (flɛ_touche("droite"))  { jo x = x + 4 }
    enyi (flɛ_touche("haut"))    { jo y = y - 4 }
    enyi (flɛ_touche("bas"))     { jo y = y + 4 }
    enyi (flɛ_touche("echap"))   { su_flɛtɛli() }

    jo souris = flɛ_souris()
    enyi (flɛ_souris_clic()) {
        xlɛ("Clic en", souris["x"], souris["y"])
    }
}

Images

FonctionRetourRôle
ɖe_yɛ(chemin, x, y) vɔ Charge et affiche une image PNG ou JPEG à la position (x, y). Cache automatique — pas de rechargement à chaque frame.
ɖe_yɛ_echelle(chemin, x, y, sx, sy) vɔ Affiche une image avec mise à l'échelle. sx=2 double la largeur, sy=0.5 divise la hauteur par deux.
ɖe_yɛ_rotation(chemin, x, y, angle) vɔ Affiche une image tournée de angle degrés (sens horaire) autour de son centre.
ɖe_yɛ_ex(chemin, x, y, sx, sy, angle) vɔ Combinaison complète : mise à l'échelle et rotation en un seul appel.
flɛ_asanhún(chemin) vɔ Joue un fichier WAV via le lecteur système (simple, non bloquant). Pour l'audio avancé voir ci-dessous.

Polices personnalisées (TTF / OTF)

Chargez n'importe quelle police TrueType ou OpenType pour afficher du texte stylisé. flɛ_fonte retourne une clé (wekwin) à passer à flɛ_signon_fonte.

FonctionArgumentsRetourRôle
flɛ_fonte(chemin, taille) wekwin, kɛn wekwin (clé) Charge un fichier TTF/OTF et le met en cache. Retourne une clé réutilisable.
flɛ_signon_fonte(texte, x, y, r, g, b, clé) wekwin, kɛn×5, wekwin vɔ Affiche du texte avec la police identifiée par la clé retournée par flɛ_fonte.
fon
hun_flɛtɛli("Fonts", 800, 600)

jo police = flɛ_fonte("assets/Roboto-Bold.ttf", 32)

azɔwanu dessin() {
    flɛ_couleur(20, 20, 30)
    flɛ_signon_fonte("Mì wá dó !", 100, 200, 255, 220, 50, police)
    flɛ_signon_fonte("Score : 42", 100, 260, 200, 200, 200, police)
}

flɛtɛli_boucle(azɔwanu() {}, dessin)

Sprites animés (spritesheet)

Un spritesheet est une image unique découpée en frames de taille égale, disposées en colonnes et lignes. flɛ_sprite_ɖɔ charge la feuille ; flɛ_sprite_ɖiɖe affiche une frame précise.

FonctionArgumentsRetourRôle
flɛ_sprite_ɖɔ(chemin, cols, rows) wekwin, kɛn, kɛn kɛn (id) Charge une spritesheet. cols = nombre de colonnes, rows = nombre de lignes.
flɛ_sprite_ɖiɖe(id, frame, x, y, sx, sy) kɛn×4, flottant×2 vɔ Affiche la frame d'index frame (0-based, gauche→droite, ligne par ligne) à (x, y) avec facteurs d'échelle sx/sy.
fon
hun_flɛtɛli("Sprite", 800, 600)

// Spritesheet 8 colonnes × 4 lignes = 32 frames
jo spr = flɛ_sprite_ɖɔ("assets/personnage.png", 8, 4)
jo frame = 0
jo timer = 0.0

azɔwanu mise_a_jour() {
    jo timer = timer + flɛ_dt()
    enyi (timer > 0.1) {      // changer de frame toutes les 100 ms
        jo frame = (frame + 1) % 8
        jo timer = 0.0
    }
}

azɔwanu dessin() {
    flɛ_couleur(30, 30, 50)
    flɛ_sprite_ɖiɖe(spr, frame, 360, 260, 2.0, 2.0)  // × 2 zoom
}

flɛtɛli_boucle(mise_a_jour, dessin)

Système audio complet

FonLang offre deux niveaux audio : les effets sonores (joués une seule fois, OGG/WAV/MP3) et la musique (boucle infinie, avec pause/reprise/volume).

L'audio Ebiten nécessite le tag de compilation ebiten_audio et la bibliothèque système libasound2-dev (Linux). Sans ce tag, les fonctions audio sont des no-ops silencieux.

Effets sonores (SFX)

FonctionArgumentsRetourRôle
flɛ_son_ɖɔ(chemin) wekwin kɛn (id) Charge un fichier OGG, WAV ou MP3. Retourne un identifiant numérique.
flɛ_son_bɔ(id) kɛn vɔ Joue l'effet sonore une fois (non bloquant).
flɛ_son_volume(id, vol) kɛn, flottant vɔ Règle le volume de l'effet (0.0 = muet, 1.0 = plein volume). Affecte les prochains plays.

Musique (boucle)

FonctionArgumentsRetourRôle
flɛ_miziki_ɖɔ(chemin) wekwin kɛn (id) Charge un fichier audio comme piste musicale en boucle infinie.
flɛ_miziki_bɔ(id) kɛn vɔ Démarre ou reprend la musique.
flɛ_miziki_su(id) kɛn vɔ Met la musique en pause (reprend avec flɛ_miziki_bɔ).
flɛ_miziki_volume(id, vol) kɛn, flottant vɔ Règle le volume de la piste (0.0–1.0).
fon
hun_flɛtɛli("Audio", 800, 600)

jo musique = flɛ_miziki_ɖɔ("assets/theme.ogg")
jo sfx_saut = flɛ_son_ɖɔ("assets/saut.wav")
flɛ_miziki_volume(musique, 0.6)
flɛ_miziki_bɔ(musique)   // démarrer la musique

azɔwanu mise_a_jour() {
    enyi (flɛ_touche_appuyee("espace")) {
        flɛ_son_bɔ(sfx_saut)   // jouer l'effet saut
    }
    enyi (flɛ_touche_appuyee("p")) {
        flɛ_miziki_su(musique)  // pause musique
    }
    enyi (flɛ_touche_appuyee("r")) {
        flɛ_miziki_bɔ(musique)  // reprendre
    }
}

azɔwanu dessin() {
    flɛ_couleur(15, 15, 30)
    flɛ_signon("Espace=saut  P=pause  R=reprendre", 20, 20, 200, 200, 200)
}

flɛtɛli_boucle(mise_a_jour, dessin)

Manette de jeu (gamepad)

FonLang supporte les manettes standard (XInput / HID). Les boutons suivent le standard Ebiten (0-based).

FonctionArgumentsRetourRôle
flɛ_manette_connectee(idx) kɛn nugbo/nuvu Retourne vrai si la manette d'indice idx (0 = première) est connectée.
flɛ_manette_bouton(idx, bouton) kɛn, kɛn nugbo/nuvu Retourne vrai si le bouton standard bouton est pressé sur la manette idx.
flɛ_manette_axe(idx, axe) kɛn, kɛn flottant Retourne la valeur de l'axe analogique (−1.0 à +1.0). Axe 0 = joystick gauche X, 1 = Y, etc.
fon
azɔwanu mise_a_jour() {
    enyi (flɛ_manette_connectee(0)) {
        // Joystick gauche — axe 0 = horizontal
        jo ax = flɛ_manette_axe(0, 0)
        enyi (ax > 0.2)  { jo joueur_x = joueur_x + 4 }
        enyi (ax < -0.2) { jo joueur_x = joueur_x - 4 }

        // Bouton 0 = A (Xbox) / Croix (PlayStation)
        enyi (flɛ_manette_bouton(0, 0)) {
            sauter()
        }
    }
}

Détection de collision

Ces fonctions sont disponibles en dehors du contexte GUI — elles s'utilisent dans la logique de mise à jour (mise_a_jour).

FonctionRetourRôle
aabb(x1,y1,w1,h1, x2,y2,w2,h2) nugbo/nuvu Retourne vrai si les deux rectangles axés se chevauchent (Axis-Aligned Bounding Box).
cercle_collide(x1,y1,r1, x2,y2,r2) nugbo/nuvu Retourne vrai si la distance entre les deux centres est inférieure à la somme des rayons.
fon
// Balle (cercle) contre un mur (rectangle)
enyi (aabb(bx-r, by-r, r*2, r*2, mx, my, mw, mh)) {
    jo dx = dx * -1   // rebond
}

// Deux balles
enyi (cercle_collide(b1x, b1y, r1, b2x, b2y, r2)) {
    xlɛ("collision !")
}

Fenêtre et timing

FonctionRetourRôle
flɛ_largeur() kɛn (entier) Largeur de la fenêtre en pixels.
flɛ_jiyiyi() kɛn (entier) Hauteur de la fenêtre en pixels.
flɛ_dt() kɛn (flottant) Delta time — secondes depuis le dernier frame. Idéal pour des mouvements indépendants du framerate.
flɛ_fps() kɛn (flottant) Nombre d'images par seconde actuelles.
fon
azɔwanu mise_a_jour() {
    jo dt = flɛ_dt()
    jo bx = bx + vitesse * dt   // mouvement indépendant du FPS
}

azɔwanu dessin() {
    flɛ_couleur(0, 0, 0)
    ɖe_yɛ("fond.png", 0, 0)
    flɛ_signon("FPS: " + toInt(flɛ_fps()), 10, 10, 255, 255, 0)
}

Exemple complet — balle rebondissante

fon
hun_flɛtɛli("Balle", 800, 600)

jo bx = 400   jo by = 300
jo dx = 3     jo dy = 2
jo r  = 20

azɔwanu mise_a_jour() {
    jo bx = bx + dx
    jo by = by + dy

    enyi (bx - r < 0 abi bx + r > 800) { jo dx = dx * -1 }
    enyi (by - r < 0 abi by + r > 600) { jo dy = dy * -1 }

    enyi (flɛ_touche("echap")) { su_flɛtɛli() }
}

azɔwanu dessin() {
    flɛ_couleur(20, 20, 40)
    flɛ_kpo(bx, by, r, 255, 80, 80)
    flɛ_signon("Appuyez Échap pour quitter", 10, 10, 180, 180, 180)
}

flɛtɛli_boucle(mise_a_jour, dessin)
Note technique — Sur Linux, FonLang utilise Ebiten avec le backend X11 (GLFW). Assurez-vous que les bibliothèques système libX11, libGL et libXxf86vm sont disponibles.

Cartes Tiled (.tmx)

FonLang peut charger directement les fichiers .tmx exportés par Tiled Map Editor. Les encodages CSV et Base64 (sans compression) sont pris en charge. Les tilesets externes (.tsx) sont résolus automatiquement depuis le même dossier.

BuiltinArgumentsRetourRôle
tuile_tiled_ɖɔ(chemin) wekwinentier (id) Charge la première couche de la carte .tmx. Retourne un id tilemap.
tuile_tiled_couche_ɖɔ(chemin, index) wekwin, entierentier (id) Charge la couche d'index index (0-based). Utile pour les maps multi-couches.
fon
// Charger une carte Tiled exportée en CSV
jo carte = tuile_tiled_ɖɔ("assets/niveau1.tmx")

// Charger une couche spécifique (ex. arrière-plan = couche 1)
jo fond   = tuile_tiled_couche_ɖɔ("assets/niveau1.tmx", 0)
jo objets = tuile_tiled_couche_ɖɔ("assets/niveau1.tmx", 1)

// Utiliser les builtins tilemap habituels
tuile_solid(carte, 3, nugbo)   // tile GID 3 = solide

azɔwanu dessiner() {
    tuile_ɖiɖe(fond, 0, 0)
    tuile_ɖiɖe(objets, 0, 0)
}

flɛtɛli_boucle(azɔwanu() {}, dessiner)
Exporter depuis Tiled — Dans Tiled : Fichier → Exporter sous…, choisissez le format TMX, encodage CSV. Placez le .tmx et l'image tileset dans le même dossier (ou pointez vers un .tsx relatif).

WebSocket

FonLang intègre un client et un serveur WebSocket pour la communication réseau temps réel. Toutes les connexions sont identifiées par un id numérique.

BuiltinArgumentsRetourRôle
ws_connecter(url) wekwinentier (id) Ouvre une connexion WebSocket client. Ex : "ws://localhost:8080".
ws_envoyer(id, message) entier, wekwinvɔ Envoie un message texte sur la connexion id.
ws_recevoir(id) entierwekwin Attend et retourne le prochain message texte (bloquant).
ws_fermer(id) entiervɔ Ferme proprement la connexion.
ws_serveur(port, fn) entier, azɔwanuvɔ Lance un serveur WebSocket sur port. fn(id, message) est appelée pour chaque message reçu. Bloquant.
fon
// ── Client WebSocket ──────────────────────────────────────────────────────────
jo id = ws_connecter("ws://localhost:8080")
ws_envoyer(id, "Bonjour serveur !")
jo reponse = ws_recevoir(id)
xlɛ("Reçu : " + reponse)
ws_fermer(id)

// ── Serveur WebSocket ─────────────────────────────────────────────────────────
// Démarre un serveur sur le port 8080 et répond à chaque message
ws_serveur(8080, azɔwanu(id, msg) {
    xlɛ("Client " + wekwin(id) + " dit : " + msg)
    ws_envoyer(id, "Echo : " + msg)
})
