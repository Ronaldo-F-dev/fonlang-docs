Structures de contrôle

Conditions, boucles et branchements — toujours entre parenthèses.

Règle universelle En FonLang, toutes les conditions sont entre parenthèses : enyi (cond), hwenue (cond), sin (…), bɔdewu (expr).

Condition — enyi / alo

Le mot enyi signifie « si » en Fon. La clause alternative alo signifie « sinon ».

fon
enyi (age >= 18) {
    xlɛ("majeur·e")
} alo {
    xlɛ("mineur·e")
}

Imbrication

fon
enyi (note >= 16) {
    xlɛ("Très bien")
} alo {
    enyi (note >= 12) {
        xlɛ("Bien")
    } alo {
        enyi (note >= 10) {
            xlɛ("Passable")
        } alo {
            xlɛ("Insuffisant")
        }
    }
}

Boucle for — sin

For classique

Syntaxe : sin (init; condition; post) { corps }

fon
// Affiche 0 à 4
sin (jo i = 0; i < 5; i++) {
    xlɛ(i)
}

// Compte à rebours
sin (jo n = 10; n > 0; n--) {
    xlɛf("%d...\n", n)
}
xlɛ("Décollage !")

For-in — ɖo

Le mot ɖo signifie « dans » en Fon. Il itère sur tableaux et chaînes.

fon
// Sur un tableau
jo pays = ["Bénin", "Togo", "Ghana"]
sin (p ɖo pays) {
    xlɛ(p)
}

// Sur les caractères d'une chaîne
sin (c ɖo "Fon") {
    xlɛ(c)    // F, o, n
}

Boucle while — hwenue

hwenue signifie « pendant que » en Fon.

fon
jo n = 1
hwenue (n <= 64) {
    xlɛ(n)
    n = n * 2
}
// 1 2 4 8 16 32 64

Boucle do-while — blo

Le corps s'exécute au moins une fois, puis répété tant que la condition est vraie.

fon
jo tentative = 0
blo {
    tentative++
    xlɛf("Tentative %d\n", tentative)
} hwenue (tentative < 3)

Switch — bɔdewu

bɔdewu signifie « selon » en Fon. À l'intérieur, enyi introduit chaque cas et alo le cas par défaut.

fon
azɔwanu nomJour(n) {
    bɔdewu (n) {
        enyi 1 { lɛkɔ "Lundi" }
        enyi 2 { lɛkɔ "Mardi" }
        enyi 3 { lɛkɔ "Mercredi" }
        enyi 4 { lɛkɔ "Jeudi" }
        enyi 5 { lɛkɔ "Vendredi" }
        alo    { lɛkɔ "Week-end" }
    }
}
xlɛ(nomJour(3))   // Mercredi

Break et Continue

nɔte / gbɔ / dɔte — break

Les trois mots-clés sont synonymes et interrompent la boucle courante.

fon
sin (jo i = 0; i < 100; i++) {
    enyi (i == 5) { nɔte }
    xlɛ(i)
}
// Affiche : 0 1 2 3 4

yinukɔn — continue

fon
// Afficher uniquement les impairs
sin (jo i = 1; i <= 10; i++) {
    enyi (i % 2 == 0) { yinukɔn }
    xlɛ(i)
}

Lever une erreur — gbɔ

Suivi d'une expression, gbɔ lève une erreur au lieu de rompre la boucle. L'erreur peut être capturée avec un bloc blokpɔn / wli.

fon
azɔwanu diviser(a, b) {
    enyi (b == 0) {
        gbɔ "Division par zéro !"
    }
    lɛkɔ a / b
}

blokpɔn {
    xlɛ(diviser(10, 2))    // 5
    xlɛ(diviser(10, 0))    // lève une erreur
} wli {
    xlɛ("Erreur :", gbogbe)
}
gbɔ seul = break, gbɔ + expression = throw
Dans une boucle, gbɔ sans valeur interrompt la boucle (synonyme de nɔte). Avec une valeur (gbɔ "message" ou gbɔ objet), il lève une erreur récupérable par wli.
